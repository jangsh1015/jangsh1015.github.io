# DS2YTO 무전 도구함

춘천(PM37)에서 쓰는 무전 계산 도구 세 가지를 한 장의 HTML에 담았습니다.
외부 라이브러리·API 없이 브라우저에서 바로 돌아가고, 파일 하나만 저장해 두면 인터넷 없이도 열립니다.

- 주소: <https://jangsh1015.github.io/ds2yto-tools/>

## 탭

### 1. 그레이 라인
- KST·UTC 시계와 춘천(37.86°N, 127.74°E) 기준 오늘 일출·일몰, 다음 그레이 라인까지 남은 시간
- 세계 지도 위 실시간 터미네이터(낮/밤 경계)와 시민·항해박명 띠, 춘천 마커
- `-12h ~ +12h` 슬라이더로 원하는 시각의 그레이 라인을 미리 확인

### 2. 전파 거리 · km/W
- Maidenhead 그리드(4~6자리) 또는 좌표 입력, 대표 교신지 프리셋
- 대권 거리(km/mi), Short·Long Path 방위각, 1W당 거리(km/W), 편도 도달 시간(ms)

### 3. 안테나 길이 · 방정식
- 주파수와 단축률(VF)로 파장, 1/4·1/2·5/8 파장, 카운터포이즈 길이 계산 (m/cm)
- 핵심 전파·안테나 방정식과 SWR↔반사계수·반사 손실
- 맥스웰 방정식 4개와 쉬운 풀이

## 계산 기준

- 태양 위치·적위·균시차는 NOAA 간이 태양 위치식으로 계산합니다. 일출·일몰은 태양 중심 고도 −0.833°(대기 굴절·태양 시반경 포함) 기준이며 실제와 1분 안팎 차이가 날 수 있습니다.
- 안테나 길이는 `λ = 300 / f` 근사를 씁니다(정확한 c=299.792458 Mm/s와 0.07% 차이). 단축률 k를 곱해 실제 전선 길이를 냅니다.
- 거리는 지구 반지름 6371.0088 km의 대권(haversine) 계산입니다. 편도 도달 시간은 빛의 속도 기준이며 실제 전리층 상태와는 다릅니다.
